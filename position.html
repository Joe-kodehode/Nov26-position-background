CSS Position

This page shows the main position values in CSS.

Static

Static is the default position. Elements stay in the normal page flow.

Static

Relative

Relative keeps the element in the normal flow like static, but lets us move it with top, right, bottom and left.

relative

Absolute

Absolute moves an element relative to its nearest relative positioned parent.

Absolute removes the element from the page flow. Be careful overlapping other elements!

Absolute
Demo

Fixed

Fixed stays in the same place even when the page scrolls.

Look at the bottom right corner of the page.
Fixed

Sticky

Sticky acts like relative until we reach a certain scroll position, then it sticks and acts like fixed.

Sticky
